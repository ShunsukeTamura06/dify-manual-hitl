# 下書きを承認して公開する

## 概要
登録された記事は最初「下書き」の状態です。人が内容を確認して承認すると公開され、
質問への回答に使われるようになります。この確認は「完全に正しいことを保証する」
ためのものではなく、「明らかにおかしいものを出さない」ための軽いチェックです。

## 対象者
マニュアルを登録した人、および内容を確認できる立場の人。特別な権限は不要です。

## 前提条件
- 承認画面の URL を知っていること（分からない場合は管理者に確認してください）

## 手順
1. 承認画面をブラウザで開く。承認待ちの記事が一覧で表示されます。
2. 確認したい記事の「内容を確認」リンクを開き、記事の中身を読む。
3. 内容に問題がなければ、一覧に戻って「承認して公開する」ボタンを押す。
4. 承認した記事は一覧から消えます。

## 内容を直してから公開したい場合
承認画面には編集機能はありません。「内容を確認」リンクから Wiki を開いて
記事を直接編集し、そのあとで承認画面に戻ってボタンを押してください。

## チャットから確認する
チャットで「承認待ちのページは？」と聞くと、下書きのままの記事の一覧が
表示されます。数が多いときの棚卸しに使えます。

## トラブルシューティング

### 承認したのに質問しても出てこない
承認してから検索に反映されるまで、少し時間がかかります。
「公開したのに検索に出ない」を参照してください。

### 承認画面が開けない
承認画面は社内ネットワークからのみアクセスできます。URL が分からない場合や
開けない場合は管理者に確認してください。

## よくある質問

### 承認は誰がやってもいいのですか
はい。複数人の承認や差し戻しの仕組みはあえて作っていません。手続きが重いと
形だけのものになってしまうためです。内容に責任を持てる人が確認してください。

### 承認を取り消したいときは
Wiki で記事を開き、先頭にある `status: published` を `status: draft` に
書き換えると下書きに戻り、検索から外れます。
