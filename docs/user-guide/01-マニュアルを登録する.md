# マニュアルを登録する

## 概要
手元にある Word / Excel / PDF などのマニュアルを、チャットに添付して送るだけで
Wiki の記事として登録できます。文章の整形は自動で行われます。登録された記事は
「下書き」の状態になり、人が確認して承認するまでは検索や質問の回答には使われません。

## 対象者
マニュアルを持っていて、みんなが検索できる状態にしたい人。全社員が対象です。

## 前提条件
- 登録したいファイル（Word / Excel / PDF / テキスト）が手元にあること
- 元のファイルがそのまま開けること（壊れていないこと）

## 手順
1. チャット画面でファイルを添付する。
2. 「登録して」など、登録したい旨を一言書いて送信する。
3. 整形が終わるまで待つ。ファイルの大きさによっては1分ほどかかります。
4. 完了メッセージに表示されたリンクから、作られた記事を開いて内容を確認する。
5. 内容に問題がなければ承認する。承認の手順は「下書きを承認して公開する」を参照。

## 大きなファイルを登録する
1つのファイルに複数の手順やトピックが入っている場合は、自動的に複数の記事に
分割して登録されます。分割してほしいことを明示したい場合は「分割して登録して」と
書いて送信してください。

## 既存の記事を更新する
すでに Wiki にある記事に新しい情報を追加したい場合は、ファイルを添付して
「○○を更新して」のように、更新したい記事の名前を書いて送信します。
既存の内容と新しい内容が統合された記事になります。元の情報は消えません。

## トラブルシューティング

### 「ファイル抽出」でエラーになる
古い形式の Word ファイル（拡張子が `.doc`）は読み取れないことがあります。
Word で開いて「名前を付けて保存」から `.docx` 形式で保存し直すか、PDF に
変換してからもう一度お試しください。

### 登録したのに質問しても出てこない
登録された記事は「下書き」の状態です。承認して公開するまでは検索の対象に
なりません。「下書きを承認して公開する」を参照してください。

### 記事の分類先（保存場所）が違う
保存先は内容から自動で判断されます。部署や業務カテゴリを指定したい場合は、
送信時に「部署は経理部です」のように書き添えてください。
登録後に Wiki 上で移動することもできます。

## よくある質問

### 元のファイルはどうなりますか
元のファイルは変更されません。内容を読み取って新しく記事を作るだけです。

### 表は残りますか
表は表のまま残ります。あわせて検索でヒットしやすいように、表の内容を説明する
文章が自動で付け加えられます。

### 間違った内容で登録してしまった
下書きの状態であれば検索には出ていません。Wiki 上で記事を編集するか、
削除してください。
