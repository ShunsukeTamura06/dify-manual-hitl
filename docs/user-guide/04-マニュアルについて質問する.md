# マニュアルについて質問する

## 概要
知りたいことを普通の文章で聞くと、社内マニュアルの内容にもとづいて回答します。
回答には必ず、根拠にしたマニュアルの名前と最終更新日が付きます。
マニュアルに書かれていないことは「見当たりません」と返し、推測では答えません。

## 対象者
社内の手順や規程を調べたいすべての人。

## 手順
1. チャットに知りたいことをそのまま書いて送信する。ファイルの添付は不要です。
2. 回答と、その根拠になったマニュアル（出典）が表示される。
3. 正確さが重要な場合は、出典のリンクから元の記事を開いて確認する。

## 回答の読み方

### 出典
回答の根拠にしたマニュアルの名前と、そのマニュアルの最終更新日が表示されます。
古い情報かどうかを判断する材料になります。

### 古い情報の注意表示
最終更新から半年以上経っているマニュアルを根拠にした場合、「この情報は
最終更新から○日以上経過しています」という注意が表示されます。
制度が変わっている可能性があるため、重要な判断に使う前に確認してください。

### 情報が食い違っている場合
複数のマニュアルで内容が食い違っているときは、どちらか一方を選ばず、
両方の記述を並べて提示します。どちらが正しいかは、出典を開いて確認するか、
担当部署に問い合わせてください。

## トラブルシューティング

### 「見当たりません」と言われる
次のいずれかの可能性があります。
- そのマニュアルがまだ登録されていない
- 登録されているが、まだ承認・公開されていない
- 言い回しが元のマニュアルと大きく違っていて、検索で見つからなかった

言葉を変えて聞き直すと見つかることがあります。それでも出てこない場合は、
そもそも登録されていない可能性が高いので、マニュアルを登録してください。

### 回答が古い内容に見える
マニュアル自体が古い可能性があります。出典のリンクから記事を開き、
必要であれば新しい資料で更新してください（「マニュアルを登録する」の
「既存の記事を更新する」を参照）。

## よくある質問

### 添付したファイルについて質問できますか
できません。ファイルを添付すると「登録したい」という意味に解釈され、
Wiki への登録が始まります。ファイルの中身について聞きたい場合は、
先に登録・公開してから質問してください。

### 回答が間違っていた場合は
元のマニュアルが間違っている可能性が高いです。出典のリンクから記事を開いて
修正してください。修正内容は次の同期で回答にも反映されます。
